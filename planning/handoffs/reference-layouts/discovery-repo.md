# Discovery Repo Reference Layout

Initial state:

```text
<project>-disc-0042-short-slug/
├── .git/
├── AGENTS.md
├── DISCOVERY.yaml
└── .governance/
    ├── SNAPSHOT.yaml
    └── <selected immutable artifacts>
```

Everything else is generated by the Discovery Repo itself.

Creation always uses the minimal layout above. Product access permits only the approved inspection or Contract Exports; it does not preload Product CI, lockfiles, dependencies, source, tests, directory conventions, or history. Later implementation choices follow the Discovery Charter and Product Access Mode.
