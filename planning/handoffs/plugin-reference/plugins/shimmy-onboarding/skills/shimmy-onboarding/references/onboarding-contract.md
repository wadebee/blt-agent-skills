# Shimmy Bootstrap Delegation Contract

The Shimmy Product repository owns:

- bootstrap implementation;
- supported platforms and prerequisites;
- installation side effects;
- version selection;
- rollback/uninstall behavior;
- post-install validation commands.

The Agent Skill owns:

- locating the authoritative bootstrap contract;
- explaining it to the user;
- gathering required choices;
- invoking it with permission;
- interpreting validation results;
- routing contributors into optional governed-development onboarding.

The skill must fail safely when Product documentation and implementation disagree.
