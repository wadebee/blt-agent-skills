# Internal Workflow: Discovery Governance Promotion

1. Confirm the Discovery Governance Promotion choice within Discovery Disposition independently of Discovery Code Promotion and repository retention. Require source Discovery Reports or Discovery Comparisons and their Conformance Proofs.
2. Distinguish Findings, Conformance Proofs, implication, target artifacts, and suggested change.
3. Allocate `GOVP-xxxx` and create it under `proposals/pending/`.
4. Mark it non-normative and pending.
5. Do not modify normative artifacts in this workflow.
6. Show changes without committing.
