# Internal Workflow: Discovery Synthesis

1. Confirm the included `DISC-*` records and comparison dimensions.
2. Compare charter, architecture, outcomes, evidence, failures, assumptions, and tradeoffs.
3. Separate convergence, divergence, and Governance ambiguity.
4. Generate non-normative `SYNTH-xxxx.md` in Governance.
5. Offer, but do not automatically create, Governance proposals.
6. Show changes without committing.
